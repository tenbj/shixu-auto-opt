# 用户流程 1.1.0

START → 读取本地记录并补齐字段 → 今日概览

随手记 → 仅填标题 → 保存为待梳理 → 完成梳理（下一步+解决标准） → 待处理 → 开始处理 → 处理中 → 必要行动完成或有理由取消 → 提交验证（处理说明+验证方式） → 待验证 → 填写验证结论 → 已解决 → END

分支：
- 创建关联行动不改变问题状态。
- 待验证 → 验证未通过（原因） → 处理中。
- 已解决 → 重新打开（原因） → 处理中。
- 主流程任一未结束阶段 → 暂缓（原因+回看日期） → 已暂缓 → 主动恢复原阶段。
- 未结束或暂缓 → 关闭（原因+类型+未完成行动处置） → 已关闭 → 重开（原因） → 待梳理。
- 重复关闭必须关联原问题。
- 零关联行动 → 直接提交观察结果和验证方式 → 待验证。
- 新增或重开必要行动 → 待验证/已解决问题回到处理中。
- 后续改进任务未完成不阻止本轮验证。
- 标题、原因或验证字段纯空白 → 拒绝并保留输入。
- 存储失败 → 显示未保存警示 → 导出保留 → END。
- 搜索/七状态筛选无结果 → 空态 → 更换条件。
- 已有记录 → 保留旧状态、内容和日志 → 补齐扩展字段 → 下一次保存写入schemaVersion=2。

## 问题池展示补充（1.1.1）

状态快捷筛选最前面提供“全部 · 总数”，点击后包含七种状态并与状态下拉框同步；保留关键词和优先级条件。每张问题卡片在标题区域展示带圆点、文字和颜色的状态徽标，手机上自动换行。

## 跟进记录与卡片呈现（1.2.0）

问题池每张卡片右下角提供“＋ 记跟进”，详情顶部也有同一入口。只需写下进展、沟通结果或阻碍即可保存，不需要改变问题状态。记录自动带时间与记录人，详情“跟进记录”按最新在前展示，卡片显示最近一条摘要与条数。

问题卡片将状态紧跟标题，操作统一在底部。行动卡片明确显示“行动 · 待办”和“问题状态：处理中”：前者是具体步骤，后者是整个问题的阶段，状态不同是正常情况。

跟进正文限制1至5000字，空白拒绝，按纯文本显示；保存失败提示导出，取消不会新增记录。人工跟进独立于自动状态与操作记录，自动记录保留在详情可展开区域。旧问题自动补空followups数组，不修改原记录。JSON导出包含完整跟进。本版仍为浏览器本地保存，不提供多用户身份或云端同步。

验证：原有50项回归与14项跟进检查通过，覆盖空白校验、安全显示、两条记录顺序、原状态不变、取消、刷新、JSON导出、卡片摘要与390px布局。

## 背景、分类与统计分析（当前1.3.0）

- 问题详情的描述区命名为“问题背景”，旁边可编辑或补充；保存返回详情，问题状态与跟进不变。
- 问题池右侧下拉改为分类筛选；优先级独立保留，状态用下方标签筛选，默认全部状态。分类来自现有问题，可与关键词、状态、优先级组合。
- 左侧新增独立“统计分析”页；今日概览四张数字卡片下只保留“查看统计分析”入口，让今日行动保持靠前。此前在今日页放完整分布图的方案已由用户追加讨论调整。
- “问题分析”页签：状态分布、分类分布，显示全部问题的数量与占比，包含已解决、已暂缓和已关闭。点击分类或状态后清空旧条件，进入对应问题列表。
- “行动分析”页签：全部行动的四状态分布；仅未完成行动（待办、进行中）的时间分布，分已逾期、今天到期、未来到期、未设日期。已完成和已取消不算逾期；暂缓问题下的未完成行动仍计入统计。
- 点击行动图进入看板，明确显示当前条件与匹配数量；可点“查看全部行动”清除筛选。状态筛选显示对应列，时间筛选展示待办与进行中。
- 各图占比以各自说明的总数为分母，百分比四舍五入。空数据不会除零；手机上两图上下排列，导航可换行。
- 验证：原有50项回归通过；背景、分类、问题分析21项检查通过；行动分析10项检查通过。覆盖计数、组合筛选、跳转清除、背景刷新、空数据和390px布局。

## 属性修改、整体流转图与复盘用途（1.4.0）

问题卡片和详情的优先级、分类带编辑标记，点击任意一项可修改两项属性。分类可选已有值或输入新值，留空为未分类。保存只改属性，不影响背景、跟进和状态。

页面右上角“状态流转”是固定帮助入口；问题详情也有“流转说明”，查看后可返回原详情。问题页签展示五阶段主线、已暂缓/已关闭分支、验证未通过、重新打开与恢复的返回目的地；行动页签展示待办/进行中/已完成/已取消和重开路线。实线表示推进，虚线表示返回。详细条件与少数特殊路径在图下可展开查看。手机在图内左右滑动，不撑宽整个页面。

复盘记录用于保存已经验证有效的解决经验：在待验证阶段填写验证结论并确认解决后收录。卡片展示验证结论，进入详情可回看背景、处理说明、跟进经过和关联行动。日常进展仍记在跟进记录；暂缓和关闭不进入复盘。问题复发可以重新打开，原记录保留，但在再次解决前不列入已解决复盘列表。本版不是单独的复盘笔记编辑器，也没有自动生成复盘结论。

验证：50项原功能回归、14项属性/帮助/复盘检查、4项整体图检查通过。

## 移动路径（REQ-016）
START → 今日首屏行动 → 开始/完成 → 成功提示 → END；有前置依赖或问题待梳理时沿用原业务拒绝与引导。
START → 底部行动 → 选择问题/状态 → 行动卡片 → 更多操作 → 编辑/前置/调序/取消 → 保存或返回 → END。
START → 问题 → 全屏详情 → 跟进/背景/关联行动编辑 → 保存返回父详情 → 返回原列表 → END。
START → 行动 → 日程 → 前后月份 → 日期分组 → 行动编辑 → END。

## 创建身份流程 REQ-017

START → 记录身份 → 使用已有身份 / 新增人或AI身份（自定义名称，AI配置工具和模型） → 随手记 → 自动带入创建信息 → 可指定人类发起者 → 填标题 → 校验 → 保存 → 列表标签 → 详情来源与模型 → END。

创建人与来源AND筛选，可清除。编辑已有记录只读创建信息；身份改名、更换模型仅影响新建。未知旧记录不猜测归属。试改独立存储，JSON导出包含身份配置。

### REQ-090 · 自定义工具（2026-10-04）

记录身份的 AI 工具列表保留四个预设，新增“＋ 其他 / 自定义工具”。选择后显示必填名称，去除首尾空格，限1至80字；大小写不敏感的同名工具复用既有来源ID。保存并使用后，工具可在身份配置、创建来源及来源筛选复用；刷新恢复、编辑回填、导出携带toolName和稳定custom:ID。账号原型按账号隔离工具，不共享到其他账号。保存失败保留表单，不关闭或显示成功。历史记录的创建人及模型快照保持不变。此次范围根据截图限定AI工具类型扩展，身份类型仍为人/AI。浏览器本地演示不代表正式系统上线。

工具字典customTools独立于身份持久化和导出，改换身份工具后仍保留原选项与历史来源；账号切换先恢复字典，再读取记录。
