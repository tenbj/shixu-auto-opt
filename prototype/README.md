# 拾序原型

当前为 v1.6.0 移动端优化原型，包含设计合同与验证材料。可运行应用见 [application](../application/README.md)。

## 查看 v1.6.0 原型

1. 下载本仓库（Code → Download ZIP）并解压。
2. 用现代浏览器打开 `prototype.html`，或打开 `mobile-preview.html` 切换360/390/430px预览。
3. 从“随手记”开始，也可以编辑页面中的虚构示例。

无需安装依赖或启动后端。GitHub 文件页展示的是源码，需下载后在浏览器中打开。

## 工作视图

| 视图 | 用途 |
|---|---|
| 今日概览 | 聚焦今天和逾期的未完成行动 |
| 问题池 | 记录背景，搜索、筛选和梳理痛点 |
| 行动看板 | 按问题、状态或日历查看行动，支持筛选、依赖和排序 |
| 统计分析 | 分页查看问题状态、分类分布，以及行动状态和未完成行动时间分布；点击图表筛选事项 |
| 复盘记录 | 保存验证结论，问题复发时重新打开 |

一个问题可以关联多个行动，行动也可以独立创建。全部行动完成不会自动解决问题；仍需填写验证依据。

## 问题状态

新问题默认进入 **待梳理**，记录时只需填写标题。

**待梳理 → 待处理 → 处理中 → 待验证 → 已解决**

- 梳理后补充下一步与解决标准，再开始处理。
- 支持暂缓并设置回看日期；恢复时回到暂缓前的阶段。
- 支持关闭、重复问题关联与重新打开，流转原因保留在问题动态中。
- 关闭前需取消或转为独立待办，避免未完成行动悬空。
- 本轮必要行动完成后才能提交验证；填写验证结论后才算解决。
- 问题卡片标题旁展示彩色状态徽标；快捷筛选支持“全部 · 总数”以及七种状态。
- v1.6.0 使用独立存储键 `shixu-mobile-prototype-v1`，不改写旧版本记录。旧记录不会自动迁入；升级前请在旧入口导出留存。

## 跟进记录

在问题卡片右下角点击“＋ 记跟进”，或在详情的“跟进记录”里点击同名按钮，写下一段进展即可保存。详情按最新在前展示完整记录，卡片显示最近跟进摘要；记录跟进不会改变状态。自动状态与操作日志单独保留在可展开区域。

行动卡片中的“行动 · 待办”表示这一具体步骤还没开始，“问题状态：处理中”表示它所属的整个问题正在处理。

## 背景、筛选与分析

问题详情的“问题背景”旁可以直接编辑或补充。问题池提供分类下拉筛选，状态用标签筛选，可与关键词和优先级组合。

左侧“统计分析”独立展示问题分析和行动分析，今日概览仅保留入口。行动时间分布只包含待办和进行中，已完成和已取消不计入逾期；点击图表进入对应的筛选看板，可一键恢复全部行动。

## 整体状态流转与复盘

桌面右上角“状态流转”、手机顶部“更多功能”可查看问题与行动的整体流转图，包含主线、异常分支和返回路径；图下可展开详细规则。问题详情也有入口，手机可在图内横向滑动。

问题卡片和详情的优先级、分类可直接点击编辑。复盘记录汇总确认解决时填写的验证结论，方便参考有效的解决办法；日常进展仍记在跟进记录，暂缓和关闭不进入复盘。

## 原型数据与边界（系统版见 ../application/README.md）

- 记录保存在当前浏览器的本地存储中，支持 JSON 导出。
- 更换浏览器、文件位置或清除浏览器数据可能导致原记录无法访问，请定期导出。
- 本版不提供 JSON 导入、登录、多设备同步或服务端。
- 初始内容为虚构演示数据，不含真实业务记录。
- `api.yaml` 和 `database.sql` 是后续工程设计合同，不代表后端已实现。

## 通用记录身份试改版

右上角“记录身份”支持任意名称的人类或AI身份，可新增、编辑和切换；AI配置工具、模型名称/ID和提供方。默认Codex身份自动填写新记录。问题池与行动看板都有创建人和来源组合筛选，列表与详情展示创建快照。

演示问题和行动统一按Codex、GPT-6、OpenAI创建，仅保留一条未知来源问题。GPT-6依据会话声明，不声称具体版本ID。创建字段及名称快照普通编辑不可修改，身份设置变更仅影响后续新记录。

本次试改使用独立存储键shixu-creator-prototype-v2，不覆盖旧版浏览器数据；导出包含身份配置。仍为本地原型，正式服务应从认证、绑定连接和调用元数据生成身份与模型。

### REQ-090 · 自定义工具（2026-10-04）

记录身份的 AI 工具列表保留四个预设，新增“＋ 其他 / 自定义工具”。选择后显示必填名称，去除首尾空格，限1至80字；大小写不敏感的同名工具复用既有来源ID。保存并使用后，工具可在身份配置、创建来源及来源筛选复用；刷新恢复、编辑回填、导出携带toolName和稳定custom:ID。账号原型按账号隔离工具，不共享到其他账号。保存失败保留表单，不关闭或显示成功。历史记录的创建人及模型快照保持不变。此次范围根据截图限定AI工具类型扩展，身份类型仍为人/AI。浏览器本地演示不代表正式系统上线。

工具字典customTools独立于身份持久化和导出，改换身份工具后仍保留原选项与历史来源；账号切换先恢复字典，再读取记录。
