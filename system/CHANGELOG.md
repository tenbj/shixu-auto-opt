# 系统变更记录

## 2.0.0 · 2026-10-01

从拾序 v1.5.0 原型落地为单人系统。保留五视图、七状态、行动依赖、固定编号、日历、跟进与复盘，新增 FastAPI、MySQL 实体表与 InnoDB 事务、持久化幂等、全局并发版本、17 个 MCP 工具、中文文档、示例、服务管理和验证脚本。根据用户指定创建独立 MySQL 日常库与测试库，原本机 SQLite 工作台只读迁入新库；SQLite 适配器仅保留作隔离测试。

新增 0.0.0.0 可配置监听及明确的内网 Host 允许列表，同源写入保护继续生效。交付离线交互 ER 图与系统架构图，ER 与 MySQL 9 表、62 字段、6 外键核对一致。

原型能力包保留；新系统位于独立 system 目录。新环境配置专属 MySQL 后使用，可显式导入合成演示数据。未自动迁移浏览器旧记录。发布包排除私有配置、数据库和真实访问截图。
