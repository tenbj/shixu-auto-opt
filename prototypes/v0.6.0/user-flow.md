# 用户流程 · r7 刷新先画外壳（v0.6.0）

## A 刷新有缓存 → 确认成功（主路径）
```
START
刷新 → HTML 外壳标记（无账号名）
 → #early-shell 读 shixu-local-user {id,displayName}
 → 首帧：工作台外壳 + 显示名 +「同步中」+ 内容骨架（REQ-005）
 → 主脚本解析完 → bootAccount：同 id 已有外壳，不重画（REQ-006）
 → GET /api/auth/me 200 同 id → 加载数据 → 填充 →「已同步」
END
```
## B 无缓存
```
刷新 → 早期脚本不画 → bootAccount → 登录页（连接 AI 品牌绿）→ test/1234 → 写缓存 → 工作台
```
## C 账号切换，不闪上一账号（REQ-007）
```
另一标签页以林夏登录 → 缓存=林夏 → 本页 storage 事件跟随 / 刷新
 → 外壳只画林夏 → 确认 → 林夏数据
会话≠缓存：外壳(缓存名) → /me 返回另一 id → 清身份 → 改写缓存 → 画确认账号 → 加载其数据
```
## D 401
```
外壳「同步中」→ /me 401 → 清缓存 → 登录页「登录已过期，请重新登录」
```
## E 非 401（502/403/超时/非 JSON/网络）
```
外壳「同步中」→ 失败 → 保留工作台「暂未同步」+ 重试（不加载数据、不踢回）→ 重试
```
## F 退出
```
退出 → 清缓存 → 登录页
```
