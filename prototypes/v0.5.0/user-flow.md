# 用户流程 · r6 登录态与连接 AI

## 主路径 A：冷启动无缓存 → 登录

```
START
  → 打开原型
  → 无 localStorage.shixu-local-user
  → 显示登录页（连接 AI 为品牌绿样式）
  → 填写 test / 1234
  → 提交 EVT-AUTH-SUBMIT
  → 写入 {id, displayName}
  → 进入工作台（已同步）
END
```

## 主路径 B：刷新有缓存 → 确认成功

```
START
  → 本地已有 {id, displayName}
  → 立刻渲染工作台 +「同步中」（REQ-002）
  → 后台 mock /api/auth/me 成功
  → 徽标变为「已同步」（REQ-003）
END
```

## 异常路径 C：确认失效 401

```
START
  → 本地已有缓存，工作台「同步中」
  → 演示控件选「确认失效 401」并模拟刷新
  → /me 返回 401
  → 清除本地缓存
  → 退回登录页，提示「登录已过期，请重新登录」（REQ-004）
END
```

## 辅助路径 D：连接 AI

```
START
  → 登录页点击「连接 AI · 查看接入指引」
  → 打开接入说明弹层（样式验收，不跳外链）
  → 关闭
END
```

## 辅助路径 E：退出登录

```
START（已登录）
  → 点击退出登录
  → 清除本地缓存
  → 登录页
END
```

## 决策

- 有本地缓存？是 → 先工作台；否 → 登录页
- 确认结果？成功 → 已同步；401 → 清缓存回登录；pending（演示）→ 保持同步中
