01 / 一套业务入口

人和 AI 使用相同规则

浏览器、API 调用方和 MCP 最终汇入 FastAPI。MCP 负责工具协议与 HTTP 适配；状态流转、依赖校验与持久化均由后端处理。

02 / 写入如何保持一致

版本 + 行锁 + 幂等

调用方携带 expected_version 和 request_id。后端先锁定 workspace_meta(id=1)；重复同指纹请求返回已保存响应，否则检查版本、执行规则并提交。

版本冲突返回 409；数据库失败返回 503。事务出错则回滚。

03 / 数据在哪里

实体、审计都保存在 MySQL

10张表的DELETE触发器阻止物理删除；应用运行时拒绝DELETE/TRUNCATE/DROP/REPLACE。行动依赖移除也保留行，仅筛选有效关联。问题和行动保存 deleted_at、deletion_batch、deleted_with_issue。普通列表过滤回收站；恢复校验父问题、同批记录与有效依赖。正式库使用独立 schema。读取时从表中组装请求快照；服务重启后仍从 MySQL 读取。身份登记保存在MySQL；浏览器仅保存当前身份ID与布局偏好。创建人、提交者、来源、模型、UTC时间为创建快照。

SQLite 适配器用于隔离测试及旧数据迁移来源。MySQL 联调使用独立的 _test 库。

04 / 运行边界

共享工作台与通用记录身份

API 默认监听回环地址，可显式配置 0.0.0.0 开放内网访问；Host 允许列表与同源检查继续生效。actor 是审计标签，当前没有账号登录或角色授权。

HTTP MCP随API生命周期启动，/mcp需Bearer密钥；stdio仍按需启动。密钥按客户端分别撤销，不等于记录身份；网页/API仍无账号认证。远程传输应使用HTTPS或加密隧道。本版不是OAuth服务。
