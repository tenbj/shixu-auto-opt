# 原型需求与系统能力映射

原型五视图复用到 static/index.html；页面使用下表 API，MCP 经 HTTP 复用相同业务规则。

| 页面/业务操作 | API | MCP | Python示例 |
|---|---|---|---|
| 检查服务与数据库状态 | `GET /api/health` | `get_system_status` | `examples/api_client.py` |
| 读取完整工作台与并发版本 | `GET /api/workspace` | `get_workspace` | `examples/api_client.py` |
| 查询通用人类与AI记录身份 | `GET /api/identities` | `list_identities` | `examples/api_client.py` |
| 创建记录身份与默认工具模型 | `POST /api/identities` | `create_identity` | `examples/api_client.py` |
| 修改身份名称与新建默认值，保留历史快照 | `PATCH /api/identities/{identity_id}` | `update_identity` | `examples/api_client.py` |
| 查询问题列表 | `GET /api/issues` | `list_issues` | `examples/api_client.py` |
| 读取问题详情及关联行动 | `GET /api/issues/{issue_id}` | `get_issue` | `examples/api_client.py` |
| 创建待梳理问题 | `POST /api/issues` | `create_issue` | `examples/api_client.py` |
| 编辑问题内容与属性 | `PATCH /api/issues/{issue_id}` | `update_issue` | `examples/api_client.py` |
| 按七状态规则流转问题 | `POST /api/issues/{issue_id}/transitions` | `transition_issue` | `examples/api_client.py` |
| 追加问题跟进记录 | `POST /api/issues/{issue_id}/followups` | `add_followup` | `examples/api_client.py` |
| 查询行动列表 | `GET /api/tasks` | `list_tasks` | `examples/api_client.py` |
| 读取行动详情 | `GET /api/tasks/{task_id}` | `get_task` | `examples/api_client.py` |
| 创建关联或独立行动 | `POST /api/tasks` | `create_task` | `examples/api_client.py` |
| 编辑行动内容与关联 | `PATCH /api/tasks/{task_id}` | `update_task` | `examples/api_client.py` |
| 推进取消或重新打开行动 | `POST /api/tasks/{task_id}/transitions` | `transition_task` | `examples/api_client.py` |
| 设置行动依赖并检查循环 | `POST /api/tasks/{task_id}/dependencies` | `set_task_dependencies` | `examples/api_client.py` |
| 调整同组行动显示顺序 | `POST /api/tasks/{task_id}/reorder` | `reorder_task` | `examples/api_client.py` |
| 读取回收站问题与行动 | `GET /api/trash` | `list_trash` | `examples/api_client.py` |
| 软删除问题及关联行动 | `POST /api/issues/{issue_id}/trash` | `delete_issue` | `examples/api_client.py` |
| 恢复问题及同批行动 | `POST /api/issues/{issue_id}/restore` | `restore_issue` | `examples/api_client.py` |
| 软删除行动并检查依赖 | `POST /api/tasks/{task_id}/trash` | `delete_task` | `examples/api_client.py` |
| 恢复独立删除的行动 | `POST /api/tasks/{task_id}/restore` | `restore_task` | `examples/api_client.py` |
| 读取操作审计事件 | `GET /api/activity` | `list_activity` | `examples/api_client.py` |
| 导出全部问题行动与版本 | `GET /api/export` | `export_workspace` | `examples/api_client.py` |

所有业务删除均为软删除；依赖移除保留原行并标记deleted_at。10表DELETE触发器和运行时SQL防护禁止物理删除。

数据层：MySQL issues/tasks/task_dependencies/issue_followups/issue_history/issue_logs保存实体；workspace_meta保存版本与编号；activity/idempotency_requests保存审计与幂等。所有业务修改在同一InnoDB事务提交，行锁保护全局版本。

未实现原型记录自动导入，源HTML与其localStorage均未改动。所有可写入口由后端规则校验，旧原型脚本不具有写库权限。

验证分别见 verification/api-report.json、browser-report.json、mcp-report.json、persistence-report.json；AI自主任务未验收。
