# 更新日志

## v2.2.1 · 2026-10-02

### 功能更新

- 问题和行动支持移入回收站、同批恢复；前置依赖取消后保留原行，重新设置时重新激活。
- 桌面使用紧凑操作菜单，手机使用底部面板；问题列表的下一步默认隐藏，可统一展开或收起。
- 系统同步维护架构和交互 ER 两个独立 HTML 页面。
- 22 个 API 操作与 22 个 MCP 工具共用持久化业务规则。

### 数据保留

- 业务删除统一通过软删除标识过滤前端展示，不物理删除数据库记录。
- 增加 9 张表的 DELETE 防护触发器与应用 SQL 防护，保留依赖关系和审计历史。

### 升级

从 2.1.x 升级时，先备份数据库并停止服务，在 application 目录执行 python scripts/migrate_trash.py，再重启。迁移追加软删除字段、索引和 DELETE 防护，保留现有业务记录。请先在测试环境验证；自定义工具若依赖物理 DELETE，需调整为软删除。

### 验证与范围

通过 46 项业务/API测试、31 项页面检查、四种尺寸回收站交互、22 个 MCP 工具固定序列、专属 MySQL 测试库数据保留与重启持久化核对。架构与 ER 页面通过浏览器几何和交互检查，ZIP 通过脱敏及换目录运行检查。

应用仍为单人服务，未加入账号权限或高可用；未进行 AI 自主任务、真实手机软键盘及跨操作系统验收。ZIP 需要 Python 3.11+ 和依赖环境；日常运行使用 MySQL 8.0。

## 2.0.0 · 2026-10-01

从拾序 v1.5.0 原型落地为单人系统。保留五视图、七状态、行动依赖、固定编号、日历、跟进与复盘，新增 FastAPI、MySQL 实体表与 InnoDB 事务、持久化幂等、全局并发版本、17 个 MCP 工具、中文文档、示例、服务管理和验证脚本。根据用户指定创建独立 MySQL 日常库与测试库，原本机 SQLite 工作台只读迁入新库；SQLite 适配器仅保留作隔离测试。
